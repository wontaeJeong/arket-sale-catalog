# ARKET 발견 목록

ARKET 한국 공식 사이트의 공개 사이트맵에서 `/ko-kr/about-arket/product.*` 링크를 모아 만든 비공식 상품 카탈로그입니다.

- 상품 이미지, 정상가·할인가, 할인율, 색상, 소재, 상품 링크
- 사이즈별 재고 여부와 수집 시각
- 상품명·색상·소재·상품번호 검색, 분류·사이즈·할인율·재고 필터
- 격자·리스트 보기, 가격·할인율 정렬

`index.html`을 브라우저에서 열면 됩니다. 데이터가 HTML에 내장되어 별도 서버가 필요하지 않습니다. 로컬 이미지가 있으면 함께 복사하세요. 로컬 이미지가 없는 경우 공식 이미지 CDN을 사용합니다.

`catalog.json`이 원본 수집 데이터이며, `python3 build.py`로 HTML을 다시 생성합니다. 상품 데이터는 자동 갱신되지 않습니다. 가격·재고는 구매 전 원본 상품 페이지에서 확인하세요. 조회가 실패한 링크도 누락하지 않고 별도 상태로 포함합니다.

GitHub Pages는 `main` 브랜치의 저장소 루트에서 제공합니다. 외부 라이브러리나 분석·추적 스크립트는 사용하지 않습니다.

ARKET과 제휴하지 않은 개인 열람용 목록입니다. 상품 이미지 및 상품 정보의 권리는 각 권리자에게 있습니다.
